# ASEMS Independent Landing Menu Views

Updated only `frontend/src/pages/LandingPage.jsx` so Home, Evaluation, and Reports & Workflow display as separate views instead of stacked sections that require continuous scrolling.

- Home displays only the landing/home content.
- Evaluation displays only the evaluation overview content.
- Reports & Workflow displays only the reporting/workflow content.
- The active menu's green underline moves with the selected menu.
- The shared header, theme toggle, Login role picker, authentication, backend, database, and other pages/features are unchanged.
