# ASEMS database design

Phase 3 deliverable. Planned entity groups include identity/permissions, organizational structure, courses/instructors, evaluation cycles, official form sections and criteria, evaluator assignments, submissions and answers, report workflow decisions, notifications, audit events, and summary results.

The final schema will preserve the official source criteria, enforce appropriate uniqueness and foreign-key constraints, and prevent final score calculation until all four weighted components are submitted. Detailed NA, rounding, and missing-response rules remain open pending institutional confirmation.
